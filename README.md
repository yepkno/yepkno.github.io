## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构与样式 |
| `app.js` | 核心逻辑（密码校验、搜索、渲染） |
| `docs.js` | 你的教学文档数据（在这里增删改内容） |
| `robots.txt` | 搜索引擎收录规则 |
| `sitemap.xml` | 站点地图（上线后把「你的域名」改成真实域名） |

## 本地预览

双击 `index.html` 即可在浏览器打开（访问密码由站长提供）。

## 修改密码

1. 打开浏览器按 `F12` 进入控制台
2. 输入 `sha256("你的新密码")` 回车，得到一串哈希
3. 打开 `app.js`，把 `PASSWORD_HASH` 的值替换成这串哈希
4. 保存即可

## 添加文档

打开 `docs.js`，复制一个 `{...}` 对象，修改 `title`、`category`、`summary`、`date`、`tags`、`content` 字段。`content` 支持 HTML 标签。

## 部署上线

本站当前部署在 **GitHub Pages**：

- 仓库：`yepkno/yepkno.github.io`（**public**）
- 发布源：`main` 分支根目录（Settings → Pages → Source: Deploy from a branch）
- 访问地址：https://yepkno.github.io/
- 更新方式：向 `main` 分支推送后 GitHub 自动构建，约 1 分钟生效

> 注意：GitHub Free 套餐的 Pages **只支持 public 仓库**——把仓库改成私有会导致站点停止发布；且 Pages 站点本身是公开访问的，与仓库可见性无关。

## 让内容被搜索引擎收录

1. 部署后，把 `sitemap.xml` 里的「你的域名」改成真实域名
2. 到 Google Search Console / 百度搜索资源平台，提交你的域名和 sitemap
3. 等待几天，搜索引擎就会收录你的首页

- 密码校验在前端完成，适合「轻量门禁」场景；若内容非常敏感，建议使用服务端鉴权的方案
- 密码正确后数据会加载到浏览器，理论上仍可被查看源码，请勿存放绝密内容
